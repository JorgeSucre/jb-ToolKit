# Contributing

Contributions are expected to preserve the long-term clarity of JB Toolkit.

Before contributing to JB Toolkit, please read:

1.  ENGINEERING_PRINCIPLES.md

2.  ENGINEERING_VERIFICATION_STANDARD.md

3.  Relevant ADRs

Engineering decisions should be evidence-based.

Contributions should preserve documented architecture.

When changing architecture, update the corresponding ADR.

When changing behavior, update documentation.

When uncertainty exists, document it rather than assume.

Thank you for helping keep JB Toolkit understandable.
