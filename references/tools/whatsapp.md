# WhatsApp

## What is it?

Native macOS desktop client for WhatsApp, mirroring the conversations on a
linked phone.

## When should I use it?

- A client wants WhatsApp available on their Mac without keeping a browser
  tab open
- Coordinating with a client over WhatsApp during a repair or support
  session

## Recommended for

- Technicians
- Clients who primarily communicate over WhatsApp

## Useful Commands

No command-line interface — WhatsApp is a GUI application.

## Workflow

1. Install and open WhatsApp.
2. Scan the QR code from a phone with WhatsApp installed to link the
   account.
3. The desktop client stays in sync with the phone afterward.

## Troubleshooting

- Problem: client logs out unexpectedly. Fix: the phone must stay
  connected to the internet; WhatsApp Desktop mirrors the phone session
  rather than running independently.
- Problem: notifications don't appear. Fix: check System Settings →
  Notifications → WhatsApp.

## Dependencies

- A phone with WhatsApp installed, used once to link the desktop session.

## JB Repair Use Cases

- Installing it for clients who request a desktop-friendly way to message
  during pickup/drop-off coordination.
