# ChatGPT

## What is it?

Native macOS desktop app for OpenAI's ChatGPT, with a global keyboard
shortcut and desktop integration.

## When should I use it?

- Quickly drafting a client-facing message or report summary
- Looking up an error message or command syntax without opening a browser

## Recommended for

- Technicians
- Power users

## Useful Commands

No CLI — this is a desktop application.

## Workflow

1. Launch the app and sign in.
2. Use the global shortcut to summon it from any application.
3. Optionally enable desktop integration for screen-aware questions.

## Troubleshooting

- Problem: app requires login every launch. Fix: confirm "stay signed in"
  is enabled in account settings.
- Problem: global shortcut doesn't trigger. Fix: check
  System Settings → Privacy & Security → Accessibility and grant the app
  permission.

## Dependencies

- None.

## JB Repair Use Cases

- Drafting a quick explanation of a fix for a non-technical client.
- Looking up an unfamiliar `smartctl` or `nmap` flag while at the bench.
