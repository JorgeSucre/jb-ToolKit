# Telegram

## What is it?

Native macOS desktop client for Telegram, a cloud-based messaging app with
multi-device sync.

## When should I use it?

- A client or team coordinates support requests over Telegram
- Receiving files/screenshots from a client without relying on email

## Recommended for

- Technicians
- Clients who primarily communicate over Telegram

## Useful Commands

No command-line interface — Telegram is a GUI application.

## Workflow

1. Install and open Telegram.
2. Sign in with a phone number; confirm via the code sent to the linked
   device.
3. Conversations sync automatically across devices (cloud-based, unlike
   WhatsApp's phone-mirroring model).

## Troubleshooting

- Problem: sign-in code never arrives. Fix: request the code again, or
  approve the login from an already-signed-in device under
  Settings → Devices.
- Problem: notifications don't appear. Fix: check System Settings →
  Notifications → Telegram.

## Dependencies

- None — Telegram accounts are cloud-based and don't require a phone to
  stay connected, unlike WhatsApp.

## JB Repair Use Cases

- Installing it for clients who request a desktop-friendly way to share
  files or coordinate support requests over Telegram.
