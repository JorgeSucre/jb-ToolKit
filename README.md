# JB Toolkit 🍺

Toolkit de mantenimiento y optimización para macOS.

## Funciones

- Setup automatizado
- Diagnóstico del sistema
- Limpieza y mantenimiento
- Optimización de rendimiento
- Reportes PDF
- Soporte Intel / Apple Silicon

## Requisitos

- macOS Monterey+
- Acceso administrador

## Uso

chmod +x jb
./jb
